# Mutian He — Next.js Portfolio

Independent Next.js recreation of the author's existing portfolio for SCU ISBA 2438 Assignment 2. The original `austin10231/my-profile`, `mutianhe.com`, DNS and deployment are never modified.

## Stack

Next.js App Router, React, TypeScript and CSS migrated from the original design. Server-side Contact validation uses Zod and a Next.js Route Handler.

## Development

Use Node.js 24, then run `npm ci` and `npm run dev`. Run `npm run build` and `npm start` for a production build.

The implementation and verification documentation is being recorded in `docs/` during development.
